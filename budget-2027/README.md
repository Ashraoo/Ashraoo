# مخطط الميزانية والأهداف ورمضان 2027 · 2027 Budget, Goals & Ramadan Planner

منتج رقمي (قالب Excel / Google Sheets) بنسختين: **عربي (RTL – جنيه)** و**إنجليزي (USD)**.

| الملف | الوصف |
|---|---|
| `dist/Planner-2027-AR.xlsx` | النسخة العربية — جاهزة للبيع |
| `dist/Planner-2027-EN.xlsx` | النسخة الإنجليزية — جاهزة للبيع |
| `build.py` | السكريبت اللي بيولّد الملفين (عدّل فيه وأعد البناء) |
| `LISTING.md` | نص صفحة البيع (Etsy / Gumroad) عربي وإنجليزي + التسعير وخطة الإطلاق |
| `ERRORS.md` | سجل الأخطاء وحلولها |

## الشيتات
1. **ابدأ هنا** — طريقة الاستخدام + الإعدادات (السنة، العملة، هدف الادخار، بداية رمضان، سعر الذهب).
2. **لوحة التحكم** — 6 مؤشرات (دخل، مصروف، صافي، نسبة ادخار مقابل الهدف، مصروف رمضان، تقدّم الأهداف) + جدول 12 شهر + رسمين بيانيين.
3. **المعاملات** — 1000 سطر، الفئة من قائمة منسدلة، والنوع والشهر وعلامة رمضان بيتحسبوا تلقائياً.
4. **الفئات والميزانية** — 8 فئات دخل + 27 فئة مصروف، خطة شهرية/سنوية مقابل الفعلي + رسم.
5. **الأهداف** — 10 أهداف: التقدّم، المتبقي، المطلوب شهرياً، الحالة (على المسار / متأخر / تم).
6. **رمضان** — ميزانية رمضان مقابل الفعلي، حاسبة زكاة (النصاب = 85 جم ذهب)، متابعة 30 يوم.

كل الأرقام معادلات حيّة (3,393 معادلة لكل ملف، صفر أخطاء بعد إعادة الحساب).
بتشتغل على Excel وLibreOffice وGoogle Sheets (ارفع الملف على Drive وافتحه بـ Google Sheets).

## إعادة البناء
```bash
python3 build.py   # يكتب dist/Planner-2027-AR.xlsx و dist/Planner-2027-EN.xlsx
```
بعد البناء لازم تعيد الحساب عشان القيم تتخزن في الملف (الملفات في `dist/` اتعاد حسابها بالفعل بـ LibreOffice).
